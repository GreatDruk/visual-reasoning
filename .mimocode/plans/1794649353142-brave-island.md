## Текущее состояние (факты)

- **Лучшее:** `002_lab_baseline` — frozen ResNet-18 layer3 (pooled) + GRU + CosineHead, pair sampler, BCE, 20 эп. → **val AUC 0.6356 / acc 0.586 / pair acc 0.595**, `twin_normalize` (только замер) → 0.6625. Конфиг в `configs/archive/002_lab_baseline.yaml`.
- **Слабые места:** категории spatial / binding / spatial_counting / spatial_negation ≈ шанс (0.48–0.49); парафразный val падает 0.636 → 0.586 — модель цепляется за формулировки, а в test есть невиданные фразировки.
- **Незакоммичено (ночная сессия):** новые головы `TransformerHead` / `QueryHead` (`src/models/fusion.py:352-478`), переделка FiLM (cosine-readout, убран zero-init, `input_pool`, `feature_dropout`), warm-start `model.init_from` (`src/train.py:68-82`), MPS-safe `adaptive_pool`. FiLM с warmup был в росте (~0.598 на эп. 8) и был убит — довести до конца.
- **Провалы:** FiLM/Query без warmup стоят на шансе (loss застрял ~1.04 — проблема градиентов/инициализации, не «модель плохая»).
- **Нет:** финального ноутбука Kaggle, заполненной таблицы Solution, утреннего отчёта; CLIP/BERT — заглушки.
- **Открытые вопросы** (`KaggleTemplate.md:37-44`): легальность `twin_normalize`, офлайн-веса при лимите 20 MB, имя колонки `label` vs `target`, парсер/DINOv2.

### 0. Гигиена (сначала, чтобы не потерять контекст)

### 1. Дешёвые улучшения на проверенной ветке (cosine)
Порядок — по ожидаемой выгоде/цене:
1. **Аугментации текста** (`configs/aug/default.yaml`, `src/text_aug.py`): перестановка клауз, логические негативы (n→n±1, left↔right) — каждому негативу пара-позитив (Kamath et al.: hard negatives без hard positives ломают устойчивость к парафразам). Плюс hflip с заменой left↔right в подписи. Цель — закрыть провал на val_para и невиданные формулировки test.
2. **`loss=bce_pair`** (pairwise-логистика по `pair_id` + `train.pair_sampler: true`) — готовый код, одна серия прогонов.
3. **Длинее учить / LR:** кривая 002 на эп. 20 ещё росла; полный run с early stopping.
4. **Backbone-свип на ровно этом рецепте** (r50/r101, layer3): прежние dbg-сравнения нечистые (разные эпохи/LR).

### 2. Spatial-рассуждения — здесь основной запас AUC
1. **Аудит text-only и image-only** (дёшево, из To-do): показывает, где вообще есть сигнал, и даёт строки в Solution-таблицу.
2. **Довести FiLM до конца:** warmup + cosine readout + `input_pool` на spatial feature map (r50/r101 layer3) — тот убитый прогон был в росте. Ранний стоп по val AUC.
3. **Починить корень шанс-уровня** FiLM/Query (loss ~1.04 не убывает): разобраться с инициализацией/градиентами (`fusion.py`), а не добавлять ещё голов.
4. Только после стабильного FiLM: `bce_pair` + аугментации поверх; Query/Transformer/MAC/RN — как кандидаты, не раньше.

### 3. Финальная модель
1. Лучший рецепт + `experiment=final` (`data.train_on_val: true`, фиксированное число эпох), 2 сида.
2. `twin_normalize`: +0.027 на val бесплатно на инференсе. Легальность не решена — решение за пользователем/staff; в любом случае в таблице отдельной строкой «+ нормализация внутри пар близнецов».
3. Опционально: ансамбль/роутинг по category — только если бюджет по времени инференса позволяет.
