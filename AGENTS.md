# Repository conventions

Final architecture is 057. The single notebook now runs cold-start orchestration066, using only original ImageNet/SigLIP input weights. Rebuild all train-derived teachers, donors, representations and models in scratch; no validation or profiling. Moodle deliverables live in ignored moodle/. Full T4 runtime and fresh public quality remain pending the user's run. Keep historical 057 as reference until that result arrives.

Public control remains 057_quality (.99978). 061–065 are not recommended for further submissions or automatic repeats. Completed 064/065 frozen-feature resolution study did not improve 057: native refit introduces one pair error, doubled input three; doubled input count MAE is .22156 versus .04368 native. Local improvement on one hidden yellow-cylinder example is insufficient for deployment. Preserve 057 and all L1/L2 anchors. Frozen evaluation scores never enter fitting. Read KaggleTemplate.md and selected YAML before changes. Test is inference/pairing only; final fresh train-to-test 50-minute execution is still unverified.

- Keep one notebook, `notebooks/base.ipynb`. Put reusable logic in `src`, finished-code checks in `tests`. Do not add experiment-specific scripts or notebook code generators to the maintained tree.
- Configurations are `configs/NNN_word.yaml`: a globally increasing three-digit ID and exactly one lowercase word. Historical IDs 001–018 are archived. Allocate the next unused ID; never recycle an ID. Explain hypotheses inside YAML, not in filenames. A seed repeat is a run of the same configuration.
- `inputs` is immutable. `.work` is scratch. `artefacts` has exactly `results`, `weights`, `kaggle`, `archive`; runtime must never read from it, including its own checkpoints. No implicit cache or checkpoint fallback into outputs.
- Put temporary analyses, pictures, validation annotations, migration helpers and local dependency work in ignored `docs/.research` or `.work`. Do not import them from maintained code or package them for Kaggle.
- Record verified findings, planned experiment status, sources and results in `KaggleTemplate.md`. Distinguish historical val, fresh training, smoke checks and confirmed Kaggle results. Report ties separately.
- Change one factor at a time. Keep the historical `r50_img + sigft` reference and documented L1/L2 anchors fixed; report incremental gains against the correct level. Keep parser/object executor fixed; the count branch has one common continuous count-likelihood across all ablations. Union repeats are complete. Research may read explicitly packaged, checksummed train-only checkpoints, donors and evaluation scores from immutable input datasets; donors must match exactly the full train scene set. This does not validate final fresh training under 50 minutes. Do not silently add all alternative models to the deployed ensemble.
- Run relevant tests. Never describe the CPU smoke checks as a full T4 training result or as validation of the 50-minute limit.

The former implementation is preserved in `docs/archive/legacy.zip` with checksums. It is historical evidence, not an active runtime dependency.
