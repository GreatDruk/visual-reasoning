## Железо

MacBook, Apple M5, 16 GB unified memory, без CUDA. Значит:
- `device: mps` с фолбэком на cpu; поставь `PYTORCH_ENABLE_MPS_FALLBACK=1`. AMP на MPS проверь, не работает — выключи.
- Память — главный риск. Кэш фич ResNet-101 layer3 (1024x20x30, fp16) ~1.2 MB на картинку, 12k картинок = ~15 GB: в RAM не влезет. Храни кэш на диске (`artefacts/features/<encoder>_<size>/` в `.npy`, memmap) или уменьши (1x1 conv до 256 каналов после кэша нельзя — кэш до проекции; тогда меньший энкодер/слой). Реши сам, обоснуй в readme.
- Перед долгими прогонами — smoke-тест на 200 примерах и 1 эпохе. Каждый прогон дольше ~2 минут запускай в фоне и жди уведомления, не поллингом.
- Kaggle-финал пойдёт на GPU с лимитом 50 минут: замерь время и оцени, влезет ли.

## План (порядок важен)

1. `uv add` недостающие зависимости, только те, что реально нужны.
2. Данные: датасет, словарь GRU только из train(+val), pair sampler, метрики (AUC, accuracy, pair accuracy, AUC по категориям). Проверь на EDA-фактах: баланс 50/50, ровно один true в паре.
3. `src.train` по образцу `run.py`: возвращает val AUC (для optuna), пишет метрики в лог hydra, сохраняет сабмит в `submissions/`.
4. Бейзлайн `experiment=lab_baseline` (train.csv only) — первая строка в таблице. Номер `001_...`, конфиг в `configs/archive/`.
5. Затем по убыванию ожидаемой пользы: FiLM на кэше ResNet → `bce_pair` vs `bce` → MAC/RN → аугментации (hflip + swap left/right, клаузы) → небольшой optuna-sweep лучшей связки, если остаётся время. CLIP — только если ResNet-ветка упёрлась.
6. Каждый основной прогон: глобальный id `00X_<name>` (не переиспользовать, даже для упавших), полный конфиг в `configs/archive/`, строка в таблицу `KaggleTemplate.md` и `readme.md`. Отладочные прогоны не архивируй.

- Не подгоняй под val: выбор модели по val AUC, но не крути сотни конфигов под 1k картинок. Разброс по сидам для лучшей модели (хотя бы 2 сида) запиши.
